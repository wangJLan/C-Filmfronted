# 1. 背景介绍

## 1.1 业务背景

### 💡 Why — 为什么要做？

> 传统电影购票 APP（淘票票、猫眼等）采用 **「搜电影 → 选影院 → 挑场次 → 看座位图 → 下单」** 的多页面跳转模式。
>
> 用户完成一次购票平均需要 **5～7 次页面跳转、3～5 分钟操作时间**。

而在大模型时代，用户交互范式正从 **「GUI 点按」→「对话式交互」** 转变。用户越来越习惯用自然语言表达需求：

<p align="center"><i>"帮我订两张明天下午离公司最近的 IMAX《流浪地球 3》"</i></p>

---

### 🏗️ 当前业务现状

一期已建设基础 H5 前端应用（`C-Filmfronted`），具备以下能力：

| 层级 | 已具备能力 | 技术实现 |
|:----:|-----------|----------|
| 🖥️ **前端框架** | React 18 + TypeScript + Umi 4 + antd-mobile 5 | H5 移动端适配 |
| 📄 **页面体系** | 首页 / 影片列表 / 详情 / 影院 / 发现 / 订单 / 钱包 / 优惠券 / 想看·看过 / 设置 / 个人中心 | 12 个页面 |
| 🧩 **核心组件** | AI 悬浮聊天助手 · 座位选择器 · 定位授权 | 3 大组件 |
| 🗃️ **状态管理** | Zustand 管理用户 / 订单 / 收藏 / 定位状态 | 4 个 Store |
| ⚙️ **后端服务** | Spring Boot · AI 对话 SSE 流式 · 用户认证 · 文件管理 | Agent 项目 |

## 2.3 角色 & 术语

### 👥 角色定义

| 角色 | 图标 | 定义 | 典型场景 |
|:----:|:----:|------|----------|
| **C 端用户** | 👤 | 使用 H5 前端购票的普通消费者 | 浏览影片、与 AI 对话购票、管理订单 |
| **B 端管理员** | 🔧 | 后台管理系统的运营人员 | 配置影片/影院/场次数据、查看销售报表、处理退票 |
| **妙语小助手** | 🤖 | AI 购票助手的拟人化名称 | 在对话中代表 Agent 与用户交互 |

### 📚 关键术语

| 术语 | 英文 | 一句话解释 |
|:----:|------|-----------|
| **意图** | Intent | 用户想干什么 — 购票？找片？修改条件？ |
| **槽位** | Slot | 完成购票的拼图块 — film / cinema / date / time / seats / count |
| **自动跳步** | Auto-Skip | 槽位齐了就别废话，直接跳到选座或下单 ⚡ |
| **动态卡片** | Dynamic Card | 聊天框里嵌的富交互 UI — 能点、能选、能支付 |
| **指代消解** | Coreference Resolution | "太贵了""换第二个" — 听懂用户在说什么 |
| **锁座** | Seat Lock | 15 分钟内只能你买，别人碰不了 🔒 |
| **进度条** | Progress Bar | 黑底高亮当前步骤 — 让你知道到哪了 |
| **用户画像** | User Profile | "IMAX 党""黄金座控""省钱达人" — 越用越懂你 |

**3. 模糊意图处理**

> 用户说"周末想看个喜剧"
>
> → 意图：`SEARCH_FILM`

> → Agent 行为：推荐符合条件的影片卡片

**4. 缺槽检测**

每次提取后检查最小槽位集合 `{ film + cinema + date + time + count }`，缺失的槽位触发追问。

### 🛠️ 3.3.3 各模块配置逻辑

<details>
<summary><b>🎬 3.3.3.1 影片管理模块</b></summary>
<br>

1. **列表展示**：表格形式 — 海报缩略图、影片名称、类型、评分、上映状态、创建时间
2. **筛选条件**：按上映状态（热映/即将/下映）、类型、年份筛选
3. **排序规则**：默认创建时间倒序，支持按评分、想看人数排序
4. **增删改查**：新增 + 编辑 + 删除（软删除，状态→"已下映"）
5. **上下架**：「即将上映」→ 一键→「正在热映」；热映 → 一键→「已下映」
6. **海报上传**：拖拽上传，自动压缩 300×400

</details>

<details>
<summary><b>🏢 3.3.3.2 影院管理模块</b></summary>
<br>

1. **列表展示**：影院名称、地址、设施标签、影厅数、营业状态
2. **筛选**：按营业状态、设施标签筛选
3. **增删改查**：新增 + 编辑 + 删除（软删除）
4. **影厅管理子模块**：每个影院下管理多个影厅，每个影厅关联一个座位模板

</details>

<details>
<summary><b>⏰ 3.3.3.3 场次管理模块</b></summary>
<br>

1. **排期视图**：日历视图或列表视图展示某影院某日全部场次
2. **快速排期**：批量创建 — 同一影片每天同一时间自动生成一周排期
3. **场次状态**：可售🟢 / 已满🔴 / 已取消⚫（撤销场次，自动退款）
4. **实时数据**：每场次实时显示已售/总座位数、销售额

</details>

<details>
<summary><b>🏠 3.3.3.4 首页配置模块</b></summary>
<br>

1. **Banner 配置**：轮播图（图片 + 跳转链接）
2. **礼包/活动配置**："新人礼包""超值券包"等营销区块
3. **推荐位配置**：热映排序权重（评分/想看人数/手动）
4. **发布生效**：配置完成后需点击「发布」→ 前台生效，支持预览

</details>
